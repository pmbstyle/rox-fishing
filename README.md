# 🎣 ROX Autofish Pro

**ROX Autofish Pro** — это современный, быстрый и надёжный автоматический бот для рыбалки в игре **Ragnarok X: New Generation**. Приложение оснащено графическим интерфейсом (GUI) в стиле Premium Dark с неоновой индикацией статусов, живым видео-превью кнопки и лог-консолью реального времени.

Бот спроектирован с акцентом на высокую скорость реакции и обход защиты от автокликеров за счет использования аппаратной симуляции ввода.

---

## ✨ Основные возможности

*   **🖥️ Графический интерфейс на CustomTkinter**: Красивая, плавная и современная темная тема с интерактивными настройками параметров.
*   **🎯 Умная автокалибровка (OpenCV Template Matching)**: Бот автоматически находит кнопку рыбалки на экране при любом разрешении и размере окна. Вам не нужно вводить координаты вручную!
*   **⚡ Мгновенная реакция (HSV Bite Detection)**: Бот анализирует экран с частотой 30 кадров/сек. Как только при клёве появляется зелёный маркер, бот отправляет клик за считанные миллисекунды, гарантируя 100% улов.
*   **👤 Имитация поведения человека**: Рандомизация задержки перед забросом удочки (от 100 до 1000 мс) и случайное смещение координат клика (в пределах ±8 пикселей) предохраняют от обнаружения.
*   **🎥 Живое превью**: Интерактивное окошко показывает увеличенное изображение кнопки рыбалки прямо сейчас, позволяя визуально контролировать процесс.
*   **⌨️ Глобальные горячие клавиши**: Запуск (`F5`) и остановка (`F6`) работают в фоновом режиме, даже если окно бота свернуто или вы находитесь в игре.
*   **🧪 Режим симуляции (Test Mode)**: Позволяет протестировать калибровку и распознавание цвета на скриншоте без запуска игры.

## 🛠️ Требования и установка

Для работы приложения необходим **Python 3.10+**.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/pmbstyle/rox-fishing.git
   cd rox-fishing
   ```

2. Установите необходимые библиотеки:
   ```bash
   pip install customtkinter opencv-python pillow pywin32 mss pydirectinput keyboard
   ```

## 🚀 Инструкция по запуску

> [!IMPORTANT]
> **Запуск от имени Администратора**:
> Если ваш эмулятор или игра запущены с правами Администратора, операционная система Windows (в целях защиты) заблокирует клики и горячие клавиши от обычных программ. 
> 
> Чтобы этого избежать, **обязательно открывайте терминал (PowerShell / CMD) от имени Администратора** перед запуском бота!

1. Откройте консоль от имени Администратора.
2. Запустите приложение:
   ```bash
   python main.py
   ```
3. Выберите окно игры (**Ragnarok X**) в выпадающем списке сверху.
4. Нажмите кнопку **CALIBRATE BUTTON**, чтобы бот зафиксировал координаты кнопки рыбалки.
5. Нажмите кнопку **START (F5)** для запуска авторыбалки.
6. Вы можете остановить работу в любой момент, нажав **STOP (F6)** или кликнув по кнопке в интерфейсе.

## ⚙️ Настройки интерфейса

*   **Click Random Offset** — радиус случайного разброса клика по кнопке (защита от детекта).
*   **Cast Click Delay** — диапазон случайной паузы перед закидыванием удочки.
*   **Green Pixel Sensitivity** — порог чувствительности к зелёному цвету (чем меньше значение, тем быстрее реакция на первую полоску клёва).
*   **Click Mechanism Mode**:
    *   *Foreground* (Рекомендуется) — активирует окно игры и совершает сверхбыстрый аппаратный клик DirectInput.
    *   *Background* (Экспериментальный) — посылает команды кликов напрямую в дочерние графические холсты эмулятора, позволяя боту рыбачить на заднем плане (окно игры может быть перекрыто другими окнами).
